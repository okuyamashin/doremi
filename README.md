# いらないコーラス

名曲「ドレミの恋」に、あなたの「ドー」を勝手に足して、台無しにします。

**https://okuyamashin.github.io/doremi/**

スマホのブラウザで開いて、マイクをオンにして「ドー」と歌うだけです。アプリのインストールはいりません。

自分の声とかいらない人は、[原曲（Suno）](https://suno.com/s/KmM0VyzcKSubFCMv)をどうぞ。

## 遊び方

1. **マイクをオン**: お手本のドが「ポーン」と1回鳴ります。
2. **「ドー」と歌う**: 音程がドに合って（±30セント以内）0.7秒続くと、勝手に録れます。オクターブはどこでも構いません。
3. **再生**: あなたの「ドー」が6人分のコーラスになって、曲のコード進行に合わせて伸びます。

歌いたくない人は「サンプルのドだけちょうだい（ごめん、許して）」を押すと、合成の「あー」で代用できます。

録った声は保存しません。リロードすると、また最初から録り直しです。

## しくみ

すべてブラウザの中（Web Audio API）で動きます。サーバーは静的ファイルを配るだけです。

| 処理 | やり方 |
|---|---|
| 音程の判定 | マイクの音を約43msごとに YIN 法で解析し、ドからのズレをセントで出す |
| 切り出し | 直近8秒をリングバッファに溜めておき、OKになった区間の前後を少し含めて切り出す |
| 音程を変える | 切り出した声の再生速度を変えて、必要な高さにする |
| 長く伸ばす | 声の安定した部分を、周期の整数倍でループさせる |
| コーラス | 推定したコードを3声に並べ、前のコードからなるべく動かない形を選ぶ。6人分を少しずつ音程・タイミング・左右をずらして重ね、残響を付ける |
| 曲 | ボーカル、原曲のコーラス、ドラム、ドラム以外の伴奏の4トラックを同時に再生 |

声の再生速度を変えているだけなので、ドから離れた音ほど早回しのような声になります。それも含めて「いらない」感じを楽しんでください。

## ファイル

| パス | 中身 |
|---|---|
| `index.html` | いらないコーラス本体（マイク → 録音 → 再生の3画面） |
| `cover.webp` | ジャケット画像 |
| `songs/doremi-vocal.m4a` ほか | Suno のステムを4トラックにまとめて AAC にしたもの |
| `songs/doremi-chords.json` | 推定したコード進行（91個、E メジャー） |
| `songs/doremi-lead.json` / `doremi-backing.json` | ボーカル・コーラスから読み取ったメロディ |
| `chorus.html` | 実験用：モード切り替え、ハモり、ミキサー、ピアノロール付きのコーラス |
| `genba.html` | 実験用：オタクの掛け声モード（拍の位置がずれるので試作のまま） |
| `tools/` | 音源とデータを作った Python スクリプト |

## データの作り方

Suno の「Stems」で書き出したパート別の WAV（48kHz）から作っています。元の WAV は大きいのでリポジトリには入れていません。必要なのは Python 3 と numpy、AAC への変換には macOS の `afconvert` を使います。

```bash
# 4トラックにまとめる（vocal / bvox / drums / other の WAV ができる）
python3 tools/make_stems.py "ドレミの恋 Stems Drams" out/
afconvert -f m4af -d aac -b 160000 out/vocal.wav songs/doremi-vocal.m4a

# メロディを読み取る（YIN で音程を出し、音符にまとめ、調も推定）
python3 tools/extract_melody.py "ドレミの恋 Stems Drams/0 Lead Vocals.wav" songs/doremi-lead.json

# コード進行を推定する（クロマ + ベースの根音 + Viterbi で平滑化）
python3 tools/estimate_chords.py "ドレミの恋 Stems Drams" songs/doremi-chords.json
```

コードの推定は完璧ではなく、Cm や Am のように調に合わないものが少し混じっています。

## 手元で動かす

マイクは `https://` か `localhost` のページでしか使えません。

```bash
python3 -m http.server 8123
```

ブラウザで http://localhost:8123 を開きます。スマホで試すときは GitHub Pages の URL を使うのが簡単です。
